# I'm Safe Check-In Test Scenarios

## Test Scenario 1: I'm Safe Button Visibility

**Objective:** Verify that the I'm Safe button is displayed.

**Steps:**
1. Open the Nirapod Poth application.
2. Navigate to the page containing the safety check-in feature.
3. Check whether the "I'm Safe" button is visible.

**Expected Result:**
The "I'm Safe" button should be displayed correctly.


## Test Scenario 2: Open Safety Confirmation Popup

**Objective:** Verify that clicking the I'm Safe button opens the confirmation popup.

**Steps:**
1. Open the application.
2. Click the "I'm Safe" button.

**Expected Result:**
A safety confirmation popup should appear.


## Test Scenario 3: Close Safety Confirmation Popup

**Objective:** Verify that the confirmation popup can be closed.

**Steps:**
1. Click the "I'm Safe" button.
2. Wait for the popup to appear.
3. Click the "Close" button.

**Expected Result:**
The popup should close successfully.


## Test Scenario 4: Check Popup Content

**Objective:** Verify the content displayed in the safety confirmation popup.

**Steps:**
1. Click the "I'm Safe" button.
2. Observe the popup.

**Expected Result:**
The popup should display a safety check-in confirmation message.
